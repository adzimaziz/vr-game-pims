# Data Sorter VR — Explore the World of PI

WebXR booth game for **Pico 4** (PICO Browser) — TNB Genco Digital & Data Booth, PIMS CoP Carnival 2026.

**Play:** open <https://adzimaziz.github.io/vr-game-pims/> in the PICO Browser → **ENTER VR** → pull **both triggers**.

| Token | Hit with |
|---|---|
| Blue hexagon — normal data | **Left** saber |
| Red flashing hexagon — anomaly | **Right** saber |

60-second rounds · wrong hand −5 · missed anomaly −10 · combos multiply the score · today's top 5 kept in the headset browser.

Options: `?round=45` for shorter rounds.
Desktop test (no headset): `Space` start · `F` left swing · `J` right swing.

Built with [three.js](https://threejs.org) (bundled in `lib/`). Background music: *tenaga-music*.
